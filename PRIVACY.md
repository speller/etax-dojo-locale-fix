# Privacy statement

This extension operates locally in your browser to set Japanese-language configuration on matching Japanese e-Tax pages before the Dojo framework loads.

- It does not collect, store, sell, or transmit personal information.
- It does not access your tax return values or send data to the extension author.
- It does not use analytics, advertising, cookies, or remote scripts.
- It changes language-related JavaScript properties and Dojo configuration only on matched web pages.

This project is independent and is not affiliated with Japan's National Tax Agency.
