# e-Tax Dojo Japanese Locale Fix

An independent Chrome Manifest V3 extension that sets the Japanese locale before legacy Dojo initializes on matching Japanese e-Tax pages. Not affiliated with Japan's National Tax Agency.

## What it actually does:

The extension loads before Dojo only on e-Tax domains and assigns the following values:

```js
navigator.language: 'ja-JP',
navigator.languages: ['ja-JP', 'ja']
navigator.userLanguage: 'ja-JP'
navigator.browserLanguage: 'ja-JP'

window.dojoConfig.locale = 'ja'
window.dojoConfig.extraLocale = []
window.djConfig.locale = 'ja'
window.djConfig.extraLocale = []
```

This extension does not alter settings on domains except `*.e-tax.nta.go.jp`!

## Installation from source

1. Open `chrome://extensions` and enable **Developer mode**.
2. Click **Load unpacked** and choose the `extension/` directory.
3. Reload the e-Tax page.
4. In DevTools console, check `window.__etaxLocaleFix` and `window.dojo?.locale`.

## Configuration

The script runs on `https://*.e-tax.nta.go.jp/*`. If the application uses another origin, update `matches` in `extension/manifest.json`, increment the version and test again. A frame on a different origin needs its own match pattern.

## Build

```bash
python scripts/build.py
```

The resulting Chrome Web Store-compatible ZIP is under `dist/`, with `manifest.json` in its ZIP root.

## GitHub Actions releases

Every push to `main` runs validation and builds a downloadable Actions artifact. Pushing a version tag such as `v1.0.0` produces a GitHub Release with the ZIP automatically. The tag must match `extension/manifest.json` version.

```bash
git init
git add .
git commit -m "Initial release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/etax-dojo-locale-fix.git
git push -u origin main
git tag v1.0.0
git push origin v1.0.0
```

Create an empty GitHub repository before adding the origin.

## Chrome Web Store

1. Register at https://chrome.google.com/webstore/devconsole and enable Google Account 2-step verification.
2. Upload a ZIP generated by `python scripts/build.py` (or GitHub Release).
3. Supply the listing description, screenshots, privacy/data-use statements, developer contact, and distribution settings.
4. Submit for Google's review. Publishing is not automatic with this starter; optionally configure Chrome Web Store API v2 after first approval.

Chrome Web Store docs: https://developer.chrome.com/docs/webstore/publish/ and https://developer.chrome.com/docs/webstore/using-api/

## Known limits

- Locale is selected before initialization, not forcefully rewritten after the page overwrites it.
- e-Tax may change its hostnames or localization implementation.
- Test on the intended site before publishing.
- Do not claim official endorsement.
